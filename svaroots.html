Work / Svaroots

Svaroots Ops: an operations dashboard for a modular sneaker brand

A modular brand breaks the metrics every commerce dashboard assumes. We designed the three that were missing, proved the gap in a live Shopify store, and shipped it.

Role
UX/UI Design, Data Visualisation, Prototyping
Team
Kirti Gupta & Digvijay Shelar
Course
Visual Interface Design & Design Management
Tools
Figma, Figma Make, GitHub, Vercel

Summary

  • The problem Svaroots sells one base sneaker with swappable textile patches. A standard dashboard can’t run that: Shopify runs the bundle calculation but never reports it.
  • What we did Audited a live Shopify store, then designed three brand-specific metrics: Customisation Rate, Patch-to-Sneaker Ratio and Bundle Readiness.
  • The result A working operations dashboard, designed in Figma, built with Figma Make, pushed to GitHub and deployed on Vercel.
